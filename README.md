# 🧠 AI Business Consultant

An AI-powered Business Consultant application designed to simulate real-world decision-making using data analysis and intelligent recommendations. This project demonstrates practical skills in AI, analytics, and full-stack development.

---

## 🚀 Project Overview

The AI Business Consultant helps users analyze business scenarios, generate insights, and make data-driven decisions. It combines chatbot interaction, data processing, and visualization into a single platform.

---

## 💡 Key Features

* 💬 AI-based chatbot for business queries
* 📊 Business insights and analytics
* 📈 Interactive dashboard using Streamlit
* 🗄️ SQLite database for local data storage
* 🔐 Secure handling of environment variables

---

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **Backend:** Python
* **Database:** SQLite
* **Libraries:** Pandas, Matplotlib, python-dotenv

---

## 🏗️ System Architecture

* **Presentation Layer:** Streamlit UI
* **Application Layer:** Business logic and AI processing
* **Data Layer:** SQLite database

## ⚙️ Setup Instructions

### 1. Clone the repository

```
git clone https://github.com/your-username/business-consultant.git
cd business-consultant
```

### 2. Create virtual environment

```
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

### 4. Create `.env` file

```
API_KEY=your_api_key_here
```

### 5. Run the application

```
streamlit run app.py
```
